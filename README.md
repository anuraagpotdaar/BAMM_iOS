## On-device GEM-X: W8 / W8A8

Choose **GEM-X → On Device**, open a view, then open **Settings → On-device
GEM-X → ViTPose precision**. The only choices are:

- **W8**: the original INT8-weight / FP16-activation Core ML model (default).
- **W8A8**: the faster activation-quantized model with the SwiGLU execution fix.

The selection persists across launches and applies to the next video generation.
It does not change BAMM text-to-motion, the denoiser, frame stride or flip test.
A missing selected model is reported as an error instead of silently using
another precision.

Build with both resources under `ARSmpl/Resources/Gemx/`:

```text
vitpose_w8.mlmodelc/
vitpose_w8a8_clipped.mlmodelc/
```

The large model files are not committed. Export and compilation instructions,
plus model hashes, are in
[GEMX_ONNX](https://github.com/wangziyannb/GEMX_ONNX).
The W8A8 option always points to the corrected package. No experimental model
choice is added to the UI.
